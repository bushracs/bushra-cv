Bushra - Portfolio Website (Design of Web-Based Systems, Assignment 3)

Live website: https://bushracs.github.io/bushra-cv/

Files
- index.html   page structure (Home, About, Skills, Projects, Contact and the other CV sections)
- styles.css   all styling, including dark mode and the mobile layout
- script.js    Assignment 2 features and the navigation menu
- api.js       API code (fetch with async/await, loading and error messages)
- images/      profile avatar

APIs used (both are free and need no API key, so nothing has to be set up)
1. GitHub API - https://api.github.com/users/bushracs/repos
   Shows my public repositories in the Projects section: name, description,
   language, stars and last update.
2. DummyJSON Quotes API - https://dummyjson.com/quotes/random
   Shows a random quote on the Home section. The "New Quote" button loads another one.
